# LeiteDia 2.3.0 — interface UX Pilot

Referência visual: `https://uxpilot.ai/s/a6f6c67a35b06b96ea3d6606c501dd47`

## Melhorias

- login redesenhado no padrão visual fornecido;
- opção **Manter conectado neste aparelho**;
- restauração automática e segura da sessão ao abrir o app;
- credenciais protegidas pelo Android Keystore;
- novo painel inicial com volume diário, volume registrado, produtores e pendências;
- atalho destacado para registrar leite;
- lista das entradas recentes no painel;
- navegação inferior: Painel, Produtores, Registrar, Histórico e Mais;
- paleta azul-marinho, azul vivo, branco e cinza claro alinhada ao protótipo;
- versão visual clara e consistente em todos os aparelhos;
- saída da conta continua apagando a sessão salva.

O administrador continua controlando usuários, dados, exportações, auditoria e backups. Cada usuário continua responsável apenas pelos próprios produtores.

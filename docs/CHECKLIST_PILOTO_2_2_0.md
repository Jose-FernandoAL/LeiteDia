# Checklist do piloto LeiteDia 2.2.0

- [ ] Instalar o APK em dois ou mais aparelhos Android 8 ou superior.
- [ ] Entrar com a conta administrativa.
- [ ] Criar dois usuários e alterar suas senhas iniciais.
- [ ] Em cada usuário, cadastrar produtores diferentes.
- [ ] Confirmar que um usuário não vê produtores ou entradas do outro.
- [ ] Registrar leite para manhã e tarde.
- [ ] Editar uma entrada e conferir os totais.
- [ ] Testar uma entrada sem internet e sincronizar ao reconectar.
- [ ] Selecionar um período e exportar a planilha de cada usuário.
- [ ] Conferir os oito dias e os totais no arquivo exportado.
- [ ] Criar e restaurar um backup de teste.
- [ ] Confirmar as mensagens antes de exclusões importantes.
- [ ] Guardar duas cópias privadas da chave de assinatura.
